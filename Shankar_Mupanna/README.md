APIs Used in the Project
GET / – Displays a welcome message from the Hotel Management API.
-

POST /register – Registers a new user with name, username, email, and password.
-

POST /login – Authenticates a user using Passport.js.
-

GET /hotels – Retrieves the list of all hotels.
-

GET /hotels/:id – Retrieves details of a specific hotel using its ID.
-

POST /hotels – Adds a new hotel to the system. Requires authentication.
-

PUT /hotels/:id – Updates the details of an existing hotel. Requires authentication.
-

DELETE /hotels/:id – Deletes a hotel using its ID. Requires authentication.
-

Express.js is used to create and handle the REST APIs.
-

Passport.js is used for user authentication and protecting hotel management APIs.
